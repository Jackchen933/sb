# 第四章：传感器驱动详解

## 4.1 IIC 通信协议

### 什么是 IIC？

**IIC (Inter-Integrated Circuit)** 是一种同步串行通信协议，只需要两根线：
- **SCL**：时钟线
- **SDA**：数据线

### IIC 通信基本流程

```
1. 发送起始信号
2. 发送从设备地址 + 写位 (0)
3. 发送寄存器地址
4. 发送数据
5. 发送停止信号
```

### 本项目的 IIC 硬件层

文件位置：`BSP/IIC/iic_hal.h`

```c
typedef struct
{
    GPIO_TypeDef * IIC_SDA_PORT;  // SDA 端口
    GPIO_TypeDef * IIC_SCL_PORT;  // SCL 端口
    uint16_t IIC_SDA_PIN;         // SDA 引脚
    uint16_t IIC_SCL_PIN;         // SCL 引脚
} iic_bus_t;
```

### 核心函数

```c
// 起始信号
void IICStart(iic_bus_t *bus);

// 停止信号
void IICStop(iic_bus_t *bus);

// 发送一个字节
void IICSendByte(iic_bus_t *bus, unsigned char cSendByte);

// 接收一个字节
unsigned char IICReceiveByte(iic_bus_t *bus);

// 写一个字节
uint8_t IIC_Write_One_Byte(iic_bus_t *bus, uint8_t daddr, uint8_t reg, uint8_t data);

// 读一个字节
unsigned char IIC_Read_One_Byte(iic_bus_t *bus, uint8_t daddr, uint8_t reg);

// 读多个字节
uint8_t IIC_Read_Multi_Byte(iic_bus_t *bus, uint8_t daddr, uint8_t reg, uint8_t length, uint8_t buff[]);
```

## 4.2 MPU6050 六轴传感器

### 简介

**MPU6050** 是一款六轴传感器，集成了：
- **三轴加速度计**：测量 X/Y/Z 三个方向的加速度
- **三轴陀螺仪**：测量 X/Y/Z 三个方向的角速度

### 用途

- **计步**：通过检测加速度变化判断走路
- **姿态检测**：计算手表的倾斜角度
- **游戏控制**：通过手势控制游戏

### IIC 地址

```c
#define MPU_ADDR 0x68  // IIC 地址
```

### 寄存器映射

| 寄存器 | 地址 | 功能 |
|--------|------|------|
| MPU_ACCEL_XOUTH | 0x3B | 加速度 X 高8位 |
| MPU_ACCEL_XOUTL | 0x3C | 加速度 X 低8位 |
| MPU_ACCEL_YOUTH | 0x3D | 加速度 Y 高8位 |
| MPU_GYRO_XOUTH | 0x43 | 陀螺仪 X 高8位 |
| MPU_PWR_MGMT1_REG | 0x6B | 电源管理 |
| MPU_DEVICE_ID_REG | 0x75 | 设备ID |

### 初始化函数

```c
u8 MPU_Init(void)
{
    // 1. 初始化 IIC 总线
    MPU_Bus_Init();

    // 2. 检查 MPU6050 是否存在
    if (MPU_Read_Byte(MPU_DEVICE_ID_REG) != MPU_ID)
        return 1;  // 失败

    // 3. 唤醒 MPU6050
    MPU_Write_Byte(MPU_PWR_MGMT1_REG, 0);

    // 4. 设置陀螺仪量程：±2000°/s
    MPU_Set_Gyro_Fsr(3);

    // 5. 设置加速度计量程：±16g
    MPU_Set_Accel_Fsr(2);

    // 6. 设置采样率：50Hz
    MPU_Set_Rate(50);

    return 0;
}
```

### 读取加速度数据

```c
u8 MPU_Get_Accelerometer(short *ax, short *ay, short *az)
{
    uint8_t buf[6];
    // 读取 6 个字节（X、Y、Z 各两个字节）
    if (IIC_Read_Multi_Byte(&MPU_IIC_BUS, MPU_ADDR, MPU_ACCEL_XOUTH_REG, 6, buf))
        return 1;

    // 合成 16 位数据（高字节 << 8 | 低字节）
    *ax = (short)((buf[0] << 8) | buf[1]);
    *ay = (short)((buf[2] << 8) | buf[3]);
    *az = (short)((buf[4] << 8) | buf[5]);

    return 0;
}
```

### 读取陀螺仪数据

```c
u8 MPU_Get_Gyroscope(short *gx, short *gy, short *gz)
{
    uint8_t buf[6];
    if (IIC_Read_Multi_Byte(&MPU_IIC_BUS, MPU_ADDR, MPU_GYRO_XOUTH_REG, 6, buf))
        return 1;

    *gx = (short)((buf[0] << 8) | buf[1]);
    *gy = (short)((buf[2] << 8) | buf[3]);
    *gz = (short)((buf[4] << 8) | buf[5]);

    return 0;
}
```

## 4.3 AHT21 温湿度传感器

### 简介

**AHT21** 是一款高精度温湿度传感器：
- 温度范围：-40°C ~ +85°C
- 湿度范围：0% ~ 100% RH

### IIC 地址

```c
#define AHT21_IIC_ADDR 0x38  // IIC 地址
```

### 数据读取流程

```c
// 1. 发送测量命令
uint8_t cmd[3] = {0xAC, 0x33, 0x00};
IIC_Write_Multi_Byte(&AHT_IIC_BUS, AHT21_IIC_ADDR, 0x00, 3, cmd);

// 2. 延时等待测量完成（80ms）
delay_ms(80);

// 3. 读取 6 字节数据
uint8_t data[6];
IIC_Read_Multi_Byte(&AHT_IIC_BUS, AHT21_IIC_ADDR, 0x00, 6, data);

// 4. 解析数据
// 湿度 = ((data[1] << 12) | (data[2] << 4) | (data[3] >> 4)) / 2^20 * 100%
// 温度 = (((data[3] & 0x0F) << 16) | (data[4] << 8) | data[5]) / 2^20 * 200 - 50
```

## 4.4 SPL06_001 气压传感器

### 简介

**SPL06_001** 是一款气压传感器：
- 气压范围：300 ~ 1100 hPa
- 用于计算海拔高度

### IIC 地址

```c
#define SPL06_IIC_ADDR 0x77  // IIC 地址
```

### 气压计算公式

```
// 气压值 = 气压原始值 / 2^精度位
// 海拔高度 ≈ 44330 * (1 - (气压/101325)^0.1903) 米
```

## 4.5 EM7028 心率血氧传感器

### 简介

**EM7028** 是一种光学心率血氧传感器，通过：
- **LED 发射光**
- **光电二极管接收反射光**
- **算法计算心率和血氧**

### 通信方式

与 MPU6050 不同，EM7028 使用 **SPI 接口** 通信。

### 数据读取

## 4.6 其他传感器

## 4.7 传感器数据读取任务

void SensorDataUpdateTask(void *argument)

    while(1)
    {
        // 1. 读取加速度计

    }

## 本章小结

1. **IIC 协议**：MPU6050、AHT21、SPL06 都使用 IIC 总线
2. **MPU6050**：加速度计+陀螺仪，用于计步和姿态检测
3. **AHT21**：温湿度测量
4. **SPL06**：气压测量，用于海拔计算
5. **EM7028**：心率血氧，使用 SPI 通信
6. **数据读取**：独立任务周期性读取传感器数据
