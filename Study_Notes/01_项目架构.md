# 第一章：项目整体架构

## 1.1 硬件平台概述

### 主控芯片：STM32F411CEUx

| 参数 | 规格 |
|------|------|
| 内核 | ARM Cortex-M4 |
| 主频 | 100 MHz |
| Flash | 512 KB |
| RAM | 128 KB |
| 工作电压 | 1.7V - 3.6V |

### 硬件资源分配

| 外设 | 用途 |
|------|------|
| SPI1 | LCD 屏幕驱动 |
| SPI2 | 心率传感器 EM7028 |
| I2C1 | 温湿度、气压、EEPROM、触摸芯片 |
| I2C2 | 六轴传感器 MPU6050 |
| ADC | 电池电压检测 |
| RTC | 实时时钟 |
| UART1 | 蓝牙串口通信 |
| TIM3 | PWM 输出（心跳灯） |
| DMA | ADC、SPI 数据传输 |

## 1.4 程序启动流程

```c
// main.c
int main(void)
{
    // 1. HAL 库初始化
    HAL_Init();

    // 2. 系统时钟配置 (100MHz)
    SystemClock_Config();

    // 3. 外设初始化
    MX_GPIO_Init();
    MX_DMA_Init();
    MX_ADC1_Init();
    MX_RTC_Init();
    MX_SPI1_Init();
    MX_TIM3_Init();
    MX_USART1_UART_Init();

    // 4. FreeRTOS 初始化
    osKernelInitialize();
    MX_FREERTOS_Init();  // 创建任务、队列、信号量

    // 5. 启动调度器（永不返回）
    osKernelStart();

    while(1); // 不会执行到这里
}
```

## 1.5 系统任务概览

本项目共创建 **13 个任务**，各有分工：

| 任务名 | 优先级 | 栈大小 | 功能 |
|--------|--------|--------|------|
| HardwareInitTask | High3 | 5KB | 硬件初始化 |
| WDOGFeedTask | High2 | 0.5KB | 看门狗喂狗 |
| IdleEnterTask | High | 0.5KB | 进入空闲模式 |
| StopEnterTask | High1 | 8KB | 进入停止模式 |
| LvHandlerTask | Low | 12KB | LVGL 任务处理 |
| KeyTask | Normal | 0.5KB | 按键处理 |
| ScrRenewTask | Low1 | 5KB | 屏幕刷新 |
| SensorDataTask | Low1 | 2.5KB | 传感器数据更新 |
| HRDataTask | Low1 | 2.5KB | 心率数据更新 |
| ChargPageEnterTask | Low1 | 5KB | 充电页面进入 |
| MessageSendTask | Low1 | 2.5KB | 消息发送 |
| MPUCheckTask | Low2 | 1.5KB | 计步检测 |
| DataSaveTask | Low2 | 2.5KB | 数据保存 |

## 1.6 消息队列

项目使用 **消息队列** 实现任务间通信：

```c
// 创建队列
Key_MessageQueue      = osMessageQueueNew(1, 1, NULL);   // 按键消息
Idle_MessageQueue    = osMessageQueueNew(1, 1, NULL);   // 空闲消息
Stop_MessageQueue    = osMessageQueueNew(1, 1, NULL);   // 停止消息
IdleBreak_MessageQueue = osMessageQueueNew(1, 1, NULL); // 空闲打破消息
HomeUpdata_MessageQueue = osMessageQueueNew(1, 1, NULL); // 主页更新
DataSave_MessageQueue = osMessageQueueNew(2, 1, NULL);  // 数据保存
```

## 本章小结

- 项目采用 **分层架构**：硬件驱动 → 操作系统 → 中间件 → 用户应用
- 使用 **FreeRTOS** 实现多任务管理，通过消息队列进行任务间通信
- **LVGL** 负责图形界面显示，与 FreeRTOS 协同工作
- 13 个任务各司其职，优先级合理分配保证系统实时性
