## 5.2 消息队列通信

### 本项目使用的消息队列

| 队列名 | 用途 | 消息类型 |
|--------|------|----------|
| Key_MessageQueue | 按键消息传递 | uint8_t |
| HomeUpdata_MessageQueue | 主界面数据更新 | uint8_t |
| IdleBreak_MessageQueue | 空闲状态检测 | uint8_t |
| DataSave_MessageQueue | 数据保存任务 | 自定义 |
| Idle_MessageQueue | 进入空闲模式 | uint8_t |
| Stop_MessageQueue | 进入停止模式 | uint8_t |

### 队列创建

```c
// 在 User_Tasks_Init() 中创建
void User_Tasks_Init(void)
{
    // 按键消息队列：1条消息，每条1字节
    Key_MessageQueue = osMessageQueueNew(1, 1, NULL);

    // 主界面更新队列
    HomeUpdata_MessageQueue = osMessageQueueNew(1, 1, NULL);

    // 数据保存队列：2条消息
    DataSave_MessageQueue = osMessageQueueNew(2, 1, NULL);
}
```

## 5.3 数据流向详解

### 传感器数据 → 显示

```c
// =====================
// SensorDataTask: 读取传感器
// =====================
void SensorDataUpdateTask(void *argument)
{
    while(1)
    {
        // 1. 读取各传感器
        MPU_Get_Accelerometer(&ax, &ay, &az);
        AHT21_Read_Data(&temp, &humi);
        SPL06_Read_Pressure(&pressure);

        // 2. 发送更新信号到主界面
        uint8_t update_flag = 1;
        osMessageQueuePut(HomeUpdata_MessageQueue, &update_flag, 0, 0);

        osDelay(1000);  // 每秒更新
    }
}

// =====================
// ScrRenewTask: 刷新屏幕
// =====================
void ScrRenewTask(void *argument)
{
    uint8_t flag;
    while(1)
    {
        // 等待主界面更新消息
        osMessageQueueGet(HomeUpdata_MessageQueue, &flag, NULL, osWaitForever);

        // 更新主界面显示
        Update_HomePage_Data();

        osDelay(10);
    }
}
```

### 心率数据流

```c
// =====================
// HRDataTask: 心率数据读取
// =====================
void HRDataUpdateTask(void *argument)
{
    while(1)
    {
        // 1. 读取心率传感器
        HR_sensor_read(&hr_value, &spo2_value);

        // 2. 更新心率 UI 变量
        HR_UI.hr_value = hr_value;
        HR_UI.spo2_value = spo2_value;

        // 3. 如果心率页面正在显示，更新界面
        if (current_page == PAGE_HR)
        {
            Update_HR_Page();
        }

        osDelay(200);  // 每200ms更新
    }
}
```

### 计步数据流

```c
// =====================
// MPUCheckTask: 计步检测
// =====================
void MPUCheckTask(void *argument)
{
    while(1)
    {
        // 1. 读取加速度
        MPU_Get_Accelerometer(&ax, &ay, &az);

        // 2. 计步算法处理
        steps = Pedometer_Calculate(ax, ay, az);

        // 3. 保存数据
        if (steps % 10 == 0)  // 每10步保存一次
        {
            DataSave_Request(steps);
        }

        // 4. 更新UI
        Update_Steps_Display(steps);

        osDelay(50);  // 20Hz 检测频率
    }
}
```

## 5.4 硬件数据访问层 (HWDataAccess)

文件位置：`User/Func/Src/HWDataAccess.c`

### 设计目的

为了**解耦**和**方便移植**，项目定义了统一的硬件接口。

### 接口定义

```c
typedef struct
{
    // RTC 接口
    HW_RTC_InterfaceTypeDef RealTimeClock;

    // 蓝牙接口
    HW_BLE_InterfaceTypeDef BLE;

    // 电源接口
    HW_Power_InterfaceTypeDef Power;

    // 屏幕接口
    HW_LCD_InterfaceTypeDef LCD;

    // IMU (MPU6050) 接口
    HW_IMU_InterfaceTypeDef IMU;

    // 温湿度传感器接口
    HW_AHT21_InterfaceTypeDef AHT21;

    // 气压传感器接口
    HW_Barometer_InterfaceTypeDef Barometer;

    // 电子罗盘接口
    HW_Ecompass_InterfaceTypeDef Ecompass;

    // 心率计接口
    HW_HRmeter_InterfaceTypeDef HR_meter;
} HW_InterfaceTypeDef;
```

### 使用示例

```c
// 获取心率
uint8_t hr = HWInterface.HR_meter.HrRate;

// 获取温度
float temp, humi;
HWInterface.AHT21.GetHumiTemp(&humi, &temp);

// 获取步数
uint16_t steps = HWInterface.IMU.GetSteps();

// 获取时间
HW_DateTimeTypeDef datetime;
HWInterface.RealTimeClock.GetTimeDate(&datetime);
```

## 5.5 页面管理

文件位置：`User/Func/Src/PageManager.c`

### 页面切换机制

```c
typedef enum {
    PAGE_HOME = 0,      // 主界面
    PAGE_HR,           // 心率
    PAGE_SPO2,         // 血氧
    PAGE_ENV,          // 环境
    PAGE_MENU,         // 菜单
    PAGE_SETTING,      // 设置
    // ... 其他页面
} PageType_t;

// 切换页面
void Page_JumpTo(PageType_t page)
{
    // 隐藏当前页面
    lv_obj_set_hidden(current_page_obj, true);

    // 显示新页面
    current_page_obj = page_obj[page];
    lv_obj_set_hidden(current_page_obj, false);

    current_page = page;
}
```

## 5.6 按键处理流程

```
按键按下
    │
    ▼
KeyTask 阻塞在 Key_MessageQueue
    │
    ▼
按键中断 / 定时扫描检测到按键
    │
    ▼
发送按键值到队列: osMessageQueuePut(Key_MessageQueue, &key, 0, 0)
    │
    ▼
KeyTask 收到消息
    │
    ▼
根据当前页面处理: Page_HandleKey(key_value)
    │
    ▼
执行相应动作（切换页面、触发功能等）
```

## 5.7 空闲检测与低功耗

### 空闲检测

在 `LvHandlerTask` 中：

```c
void LvHandlerTask(void *argument)
{
    while(1)
    {
        // 检查屏幕不活跃时间
        if(lv_disp_get_inactive_time(NULL) < 1000)
        {
            // 1秒内有操作，认为不空闲
            osMessageQueuePut(IdleBreak_MessageQueue, &idle_flag, 0, 0);
        }

        lv_task_handler();
        osDelay(1);
    }
}
```

### 进入低功耗

```c
void IdleEnterTask(void *argument)
{
    uint8_t idle_status;
    while(1)
    {
        // 等待空闲消息
        osMessageQueueGet(IdleBreak_MessageQueue, &idle_status, NULL, osWaitForever);

        // 累计空闲时间...
        // 如果超过阈值，进入低功耗模式

        osDelay(60000);  // 检查周期：1分钟
    }
}
```

## 本章小结

1. **消息队列**：6个队列用于任务间通信
2. **传感器→显示**：SensorDataTask 读取 → 队列通知 → ScrRenewTask 更新
3. **心率数据流**：独立任务读取 → UI 变量更新 → 界面显示
4. **HWDataAccess**：统一的硬件访问接口，方便代码管理和移植
5. **页面管理**：统一的页面切换机制
6. **按键处理**：中断/扫描 → 队列 → 按键任务处理
